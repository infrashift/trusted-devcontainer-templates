# Guides overview

This bundle holds the rules for the wiki: how to write, which words to use, and how to track issues and plans.

Do not put facts about the system. Put them in `architecture/`, `supply-chain/` or `operations/`.

## Find concepts

* List this bundle: read `.okfw/guides/index.md`.
* Search the guides: `okfw search "<words>" --type guide`.

## Add a concept

1. Search the wiki first. Update a concept that exists, if possible.
2. Run `okfw create "<Title>" --path guides -d "<one sentence>" --tags guide`.
3. Set `type: guide` in the frontmatter.
4. Add a link to the new concept in the list below.
5. Obey the [wiki conventions](/guides/wiki-conventions--01a1833ed3fc.md) and [Simplified Technical English](/guides/simplified-technical-english--01a1833ed3c4.md).
