# Plans overview

This bundle holds one plan concept for each piece of multi-step work, with the tag `proposed`, `active`, `done` or `dropped`.

Do not put one problem or one task. Put it in `issues/`.

## Find concepts

* List this bundle: read `.okfw/plans/index.md`.
* Search this bundle: `okfw search "<words>" --type plan`.

## Add a concept

1. Search the wiki first. Update a concept that exists, if possible.
2. Run `okfw create "<Title>" --path plans -d "<one sentence>" --tags plan`.
3. Set `type: plan` in the frontmatter.
4. Add a link to the new concept in the list below.
5. Obey the [wiki conventions](/guides/wiki-conventions--01a1833ed3fc.md) and [Simplified Technical English](/guides/simplified-technical-english--01a1833ed3c4.md).
